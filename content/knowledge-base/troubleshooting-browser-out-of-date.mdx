Shelf runs in your web browser, so it needs a browser that is recent enough to run it. If yours is too old, Shelf shows a full-screen message instead of the app:

> **Your browser is out of date**
>
> Shelf needs a current browser. Please update your browser, or switch to the latest Chrome, Firefox, Edge or Safari.

Nothing is wrong with your account or your data. The message only means this browser cannot run the app.

---

## Supported browsers

| Browser | Minimum version |
|---|---|
| **Chrome** | 98 |
| **Edge** | 98 |
| **Firefox** | 94 |
| **Safari** (Mac, iPhone, iPad) | 15.4 |

These versions came out in late 2021 and early 2022, so any browser that has updated itself since then is fine. Other browsers built on the same engines, such as Brave or Arc, work when their engine is at least as new.

The check looks at what the browser can do, not at its name. A browser below these versions gets the message above, and the app does not load behind it.

---

## How to fix it

### 1. Update your browser

Open your browser's settings and look for an update. Chrome, Edge and Firefox update themselves on most computers, so a restart of the browser is often enough.

### 2. On iPhone or iPad, update iOS

Browsers on iPhone and iPad run on the same engine as Safari, so switching from Safari to another browser app does not help. What counts is the iOS or iPadOS version: **15.4 or later** runs Shelf. Update under **Settings → General → Software Update**.

### 3. On an older Mac, check which Safari you can get

Safari updates come with macOS.

- **macOS Catalina** can update to Safari 15.6.1, which runs Shelf. Install the latest Safari update from **System Preferences → Software Update**.
- **Macs older than Catalina** cannot get Safari 15.4. Try installing Chrome or Firefox instead. If the newest version your Mac can install is still below the minimums above, use a different computer or device.

### 4. On a company-managed computer

If you cannot update the browser yourself, ask your IT team. Share the minimum versions in the table above.

---

## Still not loading?

If your browser meets the versions above and Shelf still does not load, [contact support](/contact) with:

- The browser name and version
- Your operating system and its version
- What you see on the screen
