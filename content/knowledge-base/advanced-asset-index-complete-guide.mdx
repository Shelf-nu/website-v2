The Advanced Asset Index gives you powerful ways to filter, sort, customize columns, and act on assets in bulk. This guide covers how to enable it, every feature, and common workflows.

## Enabling the Advanced Index

The Advanced Asset Index is a beta feature you enable per-workspace.

![Assets index in simple mode, with the Advanced toggle in the lower-right](https://qliecghuzfchfjwaisyx.supabase.co/storage/v1/object/public/website-images/knowledgebase/enable-advanced-1.webp)

1. **Navigate to the Assets index** and locate the **Advanced (beta)** button in the lower-right corner
2. **Click the button** to accept the beta flag — there's no risk, you can toggle back to simple mode at any time
3. **You're done** — the advanced features become available immediately

![Assets index after enabling advanced mode, showing the extended toolbar](https://qliecghuzfchfjwaisyx.supabase.co/storage/v1/object/public/website-images/knowledgebase/enable-advanced-2.webp)

> **On a phone, advanced mode steps aside.** Below tablet width the index says *"Advanced mode is currently not available on mobile"* and offers a **Change to simple mode** button. The setting is per workspace, so switching to simple on your phone switches it on your desktop too. Simple mode is the one to use on a small screen; everything in this guide is a desktop or tablet feature.

> **Feedback and requests**: the team welcomes suggestions about batch actions, column configuration, and filters. Email [hello@shelf.nu](mailto:hello@shelf.nu) or contact your account manager.

### Every Column You Can Show

**Name** is fixed and always first. Everything below it can be switched on or off and dragged into the order you want. The **Shown by default** column is what a brand-new workspace starts with, not a limit: switch any of them on whenever you need it.

| Column | Shown by default | What it holds |
|---|---|---|
| **Asset ID** | Yes | The workspace's own sequential ID, `SAM-0017` style |
| **QR ID** | Yes | The ID printed on the Shelf QR label |
| **Status** | Yes | Available, In custody, Checked out |
| **Description** | Yes | Truncated to fit the row |
| **Value** | Yes | Per-unit value. On a pooled asset this is the value of one unit, not the stock |
| **Available to book** | Yes | Whether the asset can go on a booking at all |
| **Created at** | Yes | When the asset record was made |
| **Updated at** | Yes | Last change to the record |
| **Category** | Yes | One category per asset |
| **Tags** | Yes | Two shown, the rest behind `+N` |
| **Location** | Yes | Where the asset is. Pooled stock can sit in several, so this can overflow |
| **Kit** | Yes | The kit the asset belongs to |
| **Custody** | Yes | Who is holding it |
| **Upcoming Reminder** | Yes | The next [asset reminder](/knowledge-base/asset-reminders) due |
| **Upcoming Bookings** | Yes | Bookings this asset is committed to |
| **Actions** | Yes | The per-row menu |
| **ID** | No | Shelf's internal record ID, the one the [bulk update](/knowledge-base/bulk-updating-assets-via-csv) flow matches rows on |
| **Quantity** | No | Units held, for [quantity-tracked](/knowledge-base/quantity-tracked-assets-and-consumables) assets |
| **Min quantity** | No | The low-stock threshold |
| **Tracking method** | No | Individually tracked or quantity-tracked |
| **Asset model** | No | The [asset model](/glossary/asset-models) the unit belongs to |
| **Code128**, **Code39**, **DataMatrix**, **External QR**, **EAN-13** | Yes, when barcodes are on | One column per barcode type. See [Alternative Barcodes](/knowledge-base/alternative-barcodes) |
| Your custom fields | No | One column per field you have defined |

The five barcode columns only exist once **Alternative Barcodes** is enabled on the workspace. They are added switched on, so they appear the first time you look after enabling.

**Total value** is not in this list, and that is on purpose. It is written into CSV exports as a separate column, so a pooled asset's per-unit **Value** and its total both reach the spreadsheet, but it is not a column you can put on screen. See [Exporting Data from Shelf](/knowledge-base/export-exporting-workspace-data-from-shelf).

### When a Cell Holds More Than It Can Show

A table cell sets the height of its row, so a cell that stacked everything it held would stretch every other column in that row with it. Columns that can hold several values cap what they render on one line and collapse the rest into a small `+N` control:

- **Tags** and the five **barcode** columns show two, then `+N`
- **Location**, **Kit** and **Custody** show the primary one, then `+N`

Hover or tab to a `+N` and it lists what is hidden. On a barcode column it does more than that: clicking `+N` opens the code preview on the first hidden barcode, and the dialog's own selector reaches the rest, so a code past the cap is still one click from being displayed large enough to scan off the screen.

This is why a row stays the same height whether an asset carries one barcode or six.

## Advanced Filtering System

### Text Fields (Name, Category, Location, etc.)

- **is**: Exact match (e.g., `Location is "Server Room"`)
- **is not**: Excludes exact match (e.g., `Category is not "Computers"`)
- **contains**: Partial match (e.g., `Description contains "wireless"`)
- **matches any**: Multiple exact matches
- **contains any**: Multiple partial matches

### Number Fields (Value)

- **is**: Exact value (e.g., `Value is 1200`)
- **is not**: Excludes value
- **greater than**: Above value (e.g., `Value greater than 5000`)
- **less than**: Below value
- **greater or equal**: Minimum value
- **lower or equal**: Maximum value
- **between**: Value range (e.g., `Value between 1000 and 5000`)

### Date Fields (Created At, Purchase Date, etc.)

- **is**: Specific date
- **is not**: Exclude date
- **before**: Before date
- **after**: After date
- **between**: Date range
- **in dates**: Multiple specific dates

### Boolean Fields (Available to Book, Is Portable)

- **is**: Yes/No selection

### Tags

- **contains**: Has specific tag
- **contains all**: Has all specified tags
- **contains any**: Has any of specified tags

### Low stock only

The **Filter** panel carries a single checkbox, **Low stock only** (*at or below reorder threshold*), just above the **Add filter** row. It narrows the list to [quantity-tracked assets](/knowledge-base/quantity-tracked-assets-and-consumables) whose available count has reached or fallen below their **Min quantity**, and it applies immediately rather than waiting for **Apply filters**.

It stacks with everything else, so you can combine it with a location or category filter to see what a single stockroom needs. It also counts toward the filter badge on the **Filter** button and clears with **Clear all filters**. Add **Min quantity** from the column picker to see each item's threshold next to its live count.

## Natural and Advanced Sorting

### Natural Sorting

The system uses natural sorting for logical number ordering:

**Traditional Sorting:**
- Scanner 1
- Scanner 10
- Scanner 11
- Scanner 2
- Scanner 3

**Natural Sorting (Shelf):**
- Scanner 1
- Scanner 2
- Scanner 3
- Scanner 10
- Scanner 11

**Benefits:**
- Numbers sort logically within names
- Equipment series appear in proper order
- Serial numbers sort correctly
- Case-insensitive ordering

### Multi-Field (Stacked) Sorting

You can build complex sort orders:

1. Primary sort sets main grouping
2. Secondary sort organizes within groups
3. Additional sorts provide final ordering

**Example:** Sort by Category, then Value, then Name:

```
Computers
  - Laptop ($2,000) - "Dell XPS"
  - Laptop ($1,500) - "HP Elite"
  - Desktop ($1,200) - "iMac"

Networking
  - Switch ($5,500) - "Cisco"
  - Router ($350) - "Netgear"
  - Access Point ($180) - "Ubiquiti"
```

## Export Capabilities

Select the assets you want (or **Select all X entries** to take the whole filtered set), click **Export selection**, and choose how the file is built:

- **Format**: **Standard** for a readable spreadsheet, or **Import-ready** for a file that uploads straight back into another workspace via **Assets → Import**
- **Columns**: only the columns currently visible in your index, or all of them

A Standard export is perfect for:

- Inventory reports
- Audit preparation
- Budget planning
- Maintenance schedules

Full reference: [Exporting Data from Shelf](/knowledge-base/export-exporting-workspace-data-from-shelf).

## Troubleshooting

### No Results?

- Check filter spelling
- Try broader criteria
- Verify date formats (YYYY-MM-DD)
- Remove some filters temporarily

### Too Many Results?

- Add more specific filters
- Combine multiple filter types
- Use exact matches instead of contains
- Add date ranges to narrow scope

### Performance Issues?

- Reduce visible columns
- Remove unused filters
- Clear filters after use
- Export large datasets instead of viewing

### Export Issues?

- Verify column selection
- Check filter combinations
- Ensure reasonable dataset size
- Confirm file permissions
