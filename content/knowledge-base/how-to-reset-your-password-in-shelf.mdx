Keeping your account secure is essential when managing your asset inventory. This guide will walk you through the process of resetting your password in Shelf.

## Method 1: Reset from Account Settings (When Already Logged In)

If you're already logged into your Shelf account and want to change your password:


![Method 1: Reset from Account Settings (When Already Logged In)](https://cdn.prod.website-files.com/641c35b7e5057648c76fa79f/681a0c7662f1cdff4d0ccad2_account%20settings.jpg)

![Method 2: Reset from Login Page (When LogedOut)](https://cdn.prod.website-files.com/641c35b7e5057648c76fa79f/681a0cc0a94d4a5e8d4f86ca_resetpassword.jpg)

![Method 2: Reset from Login Page (When LogedOut)](https://cdn.prod.website-files.com/641c35b7e5057648c76fa79f/681a0d1d6fee5b6a4525a0e0_resetpasswordbutton.jpg)
1. Navigate to [app.shelf.nu](https://app.shelf.nu/)
2. Click on your user profile picture in the bottom left corner of the sidebar
3. From the dropdown menu, select **Account settings**
4. On the account details page, scroll down to the **Password** section
5. Click the "Reset password" button
6. This will log you out and trigger the password reset flow

## Method 2: Reset from Login Page (When Logged Out)

If you've forgotten your password and cannot log in:

1. Go to the [Shelf login page](https://app.shelf.nu/login)
2. Click the "Forgot password?" link
3. Enter your email address associated with your Shelf account
4. Click "Reset password"
5. Check your email inbox for a one-time code (also check spam/junk folders if not found)
6. Enter the code to set your new password

## The screen looks the same whether or not a code was sent

Shelf answers every address the same way. Type anything into **Forgot password?** and you are taken to the same "we've sent a 6-digit code" screen, with the same wording, whichever address you used.

That is deliberate. If the page said "no account with that email", anyone could feed it a list of addresses and learn which ones belong to Shelf accounts. So the page tells you nothing it would not tell a stranger, and the code itself is what proves the account exists: it only ever goes to a real account that signs in with a password.

Two reasons a code never arrives, neither of which the screen can tell you apart:

- **No Shelf account uses that address.** Check for a typo, and check whether you signed up with a different address (a work one rather than a personal one, for example).
- **Your account signs in with SSO.** Accounts that arrive through single sign-on have no Shelf password to reset, so there is nothing to send. Go back to the [login page](https://app.shelf.nu/login) and use **Login with SSO** instead. Your identity provider handles the password, and anything you change there applies to Shelf straight away.

If neither fits, [contact support](/contact) rather than requesting more codes.

## Important Notes

- Password reset emails are typically delivered within a few minutes
- Make sure to create a strong, unique password
- If you don't receive the code, check your spam folder first, then read the section above
- For security reasons, the code expires after a short period. **Request new code** on the same screen sends a fresh one
