An over-the-air update went out to **Shelf Companion** on iPhone and Android on 15 October 2026. The version number stays **1.5.0**. The app picks up an update like this in the background when you open it and uses it the next time you open it, so there is nothing to fetch from the store.

## The Manager role, on the phone

The [Manager](/knowledge-base/user-roles-and-their-permissions#manager) role arrived on the web the same morning. On the phone a Manager now gets the same reach: every booking in the workspace, with check-out, check-in and the whole team in the custodian picker; custody hand-offs to anyone; any audit, assigned or not; and the whole catalogue to read, without the edit controls an Administrator has. Before this update the app did not know the role and showed a Manager what a Base user sees.

## Read the whole description

A booking or audit description longer than three lines ends in **Show more**. Tap it to read the rest, and **Show less** to fold it back. Until now the text was cut off on the phone with no way to open it.

## A link opens the record it names

With a booking open, following a link to a second booking kept showing the first one; the audit screen had the same bug. Each now opens the record the link names, with its own selection, search and open sheets.

## A character count on asset descriptions

**New asset** and **Edit** show how many characters the description holds and its limit of 5,000, the same limit the web applies.

The iPad layout and Android tablet rotation that were merged this week are native changes and wait for the 1.6.0 store build; they are not part of this update.
