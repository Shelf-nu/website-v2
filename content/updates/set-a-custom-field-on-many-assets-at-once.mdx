Category, location and tags could already be set on many assets at once, but a custom field such as *Brand* or *Supplier* meant editing one asset at a time, or exporting, editing and re-importing a spreadsheet. Now select the assets on the asset index, open **Actions → Set custom field**, pick the field and a value, and confirm.

By default Shelf only fills assets that have no value for that field, and leaves the rest alone; choose **Replace their value** to overwrite them too. The value input follows the field's type (dropdown, yes or no, date, number or text), a field limited to certain categories skips assets in other categories, and the message afterwards says how many assets changed and why any were left alone. Each changed asset's activity records the new value, just as a single edit does.
