A [quantity-tracked asset](/knowledge-base/quantity-tracked-assets-and-consumables) can sit in several places at once: 60 cables in the stockroom, 40 in the van. The web asset page has always shown that spread. In [Shelf Companion](/mobile-app), the asset screen showed a single location and could only move the whole pool.

Now the asset screen lists every location that holds units, each with its count, plus the units a kit holds and the units not placed anywhere. Tap **Placements** to open **Manage Placements**: add or remove locations, set how many units sit at each with a stepper, and check the **Placed / Via kits / Unplaced** meter before you save. It uses the same rules as the web, so placements can never add up to more than the asset owns, and every change lands in the asset's activity. Units a kit holds are shown but move with the kit.

Individually tracked assets keep the single location picker.

This reached every phone on version 1.5.0 as an over-the-air update. The app picks it up in the background and shows it the next time you open it, with nothing to install from the store.
