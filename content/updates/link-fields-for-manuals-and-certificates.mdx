Keep each asset's user manual, calibration certificate or project folder one click away, without moving the file. In **Settings → Custom fields**, create or edit a single-line text field and set its **Format** to **Link**. The field then only accepts a web link, in the asset form, inline edits, bulk edits, Shelf Companion and CSV imports (`cf:User manual,type:text,format:link`).

On the asset page and in the advanced index, the link shows as a short link with the page's title when Shelf can read it, or what it is and where it lives, such as *PDF · SharePoint* or *Folder · Google Drive*. Anyone who can edit assets can give a link a clearer name for the whole workspace. Links pasted into notes, recorded in activity lines or written in an asset description read the same way instead of as a long address.
