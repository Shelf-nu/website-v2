Requesting a one-time code for an address with no Shelf account used to stop on the login form with the text *Signups not allowed for otp* in red. An address with an account went on to the code page instead, so the two answers told anyone trying addresses which ones are registered, and people who had mistyped their own address kept retrying against an error that explained nothing.

Since 27 October 2026 every address gets the same answer: the code page. Its wording is honest about what happened: *If you@example.com can sign in with a code, we have sent one to it*, and **Send again** replies *If this address can receive a code, a new one is on its way*. An address with no account, or one that signs in with SSO, is sent nothing, and the page does not say which it is. If no code arrives, check the spelling of the address, then the [delivery checks](/knowledge-base/troubleshooting-invite-not-received). Password sign-in already answered unknown and known addresses alike.
