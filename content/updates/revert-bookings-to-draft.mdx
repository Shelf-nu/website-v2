A reserved booking no longer has to be cancelled just because something about it needs to change. Open the booking, choose **Revert to Draft** from the **Actions** menu, and it returns to **Draft** with everything still on it — the same assets, kits, dates and custodian — ready to be edited and reserved again.

Use it when a reservation request needs a change rather than a refusal: a different week, one more camera, the wrong custodian. Cancelling would end the booking and read as a rejection; reverting keeps it alive and hands it back for another pass.
