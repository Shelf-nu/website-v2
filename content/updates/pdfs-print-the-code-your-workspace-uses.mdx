The two sheets that Shelf prints, the booking checklist and the audit receipt, used to put a QR square in their code column and nothing else. A workspace whose physical labels carry SAM IDs got a page it could not match to a shelf without a scanner.

Both now print the asset's code as **text**, in whichever format the workspace has chosen under **Settings → General ▸ Preferred display code**. SAM ID workspaces get `SAM-0042`. The default QR Code ID workspaces get the QR id, which previously appeared nowhere on the sheet. Workspaces with the [alternative-barcodes add-on](/knowledge-base/alternative-barcodes) get the barcode value, because a printed value needs no barcode image behind it, so barcode types reach the sheets even though they do not yet reach downloaded labels. Where an asset has no code of the preferred type, its QR Code ID prints with the type name in small text underneath, which is the same thing the on-screen chip explains in a tooltip.

The audit receipt's column header changes from **QR Code** to **Code** to match.

## A new switch: Print QR codes on PDFs

The QR square on a checklist is the same code as the sticker on the item. A phone cannot tell them apart, so scanning the sheet during a pack-out or an audit records a scan without anyone going near the equipment.

**Settings → General ▸ QR codes on PDFs** now carries a **Print QR codes on PDFs** switch that removes the image from both sheets. It is on by default, so nothing changes until you turn it off, and the code prints either way, so a row stays matchable by eye without it. Rows get shorter too: a 14-row audit receipt loses about 250px of table height.

It is a workspace setting rather than a checkbox on the print dialog, on purpose. A control the person taking the shortcut can untick before printing is not a control. It is available on every plan and is not gated behind an add-on.

This narrows the shortcut rather than closing it. Shelf still lets you print labels away from the equipment, through the bulk QR download and the per-asset label print, because that is what label printing is for.
