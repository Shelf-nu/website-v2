On a booking's **Add assets** dialog, ticking a parent location whose assets sit in its sub-locations showed an empty list, with no hint why: the **Locations** filter matched the ticked location exactly. Now, when a ticked location has [child locations](/knowledge-base/sublocations-organize-locations-into-hierarchies), a checkbox **Include assets from child locations** appears under the filter. Tick it and the list adds every asset kept below the ticked locations, and **Select all** picks the same set, so a whole building can go on a booking in one pass.

The checkbox is off by default, hidden for a location without children, and works the same way as the one the **Start audit** dialog already offers for a location. The kit page's and the location page's asset pickers keep exact matching.
