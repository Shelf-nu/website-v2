The value you set on an asset has always been its **per-unit** value. Now that assets can be [tracked by quantity](/knowledge-base/quantity-tracked-assets-and-consumables), Shelf multiplies that per-unit value by the quantity on hand to get the pool's true total worth — a box of 100 cables at €2 each counts as €200, not €2.

That quantity-aware total now flows through every place value is summed: the dashboard inventory-value tile, location and kit totals, a booking's total asset value (including the pull-list PDF), the value-based reports (Asset Distribution, Asset Inventory, Idle Assets, Custody Snapshot, Overdue Items), and CSV exports. Individually tracked assets are unchanged — with a quantity of one, per-unit and total are the same number.
